# Streak Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every roster avatar carries an icon for its unbroken run of submitted rounds; it flares when it grows, and my own flare rings a triangle.

**Architecture:** `RoundPlayPoints` derives `streak` from the rows it already loads for the points, under the same window and live gate, and the roster ships it as a top-level `streak: Int`. The frontend maps it to band, size and position (`members/streak.ts`), draws it (`members/StreakMark.vue`), and `MemberRow` holds a grown streak for `VERDICT_MS` before flaring it — plus `playTriangle()` for my own row.

**Tech Stack:** Kotlin/Spring Data JDBC, kotest + Testcontainers; Vue 3, Vitest + happy-dom + fake timers, Web Audio via `ui/soundOutput`.

**Spec:** `docs/superpowers/specs/2026-11-23-streak-design.md`

## Global Constraints

- Submitted = `game.round_plays.points IS NOT NULL` (guess or give-up). Opened only does not count.
- Game round = a `game.round_games` row of the active edition with `windowReasonOf(edition, n) == null`. Rounds without such a row are skipped, never break.
- Live gate as for points: the running round counts only when the viewer submitted it, and only for members who submitted it too. Otherwise counting starts at `current − 1`.
- Bands: `<3` none · `3–9` flame orange · `10–19` flame blue · `20–32` diamond ice · `33–49` diamond ruby · `≥50` ruby with glint.
- Size `s(n) = 14 + 12 · ln(min(n, 50) − 2) / ln(48)` px; position `left = 38.8 − s·0.5`, `top = 9.2 − s·0.9` relative to the 48px avatar; `transform-origin: 50% 90%`.
- SVG paths, colours, flare keyframes and triangle partials: copy verbatim from the spec (sections *Formen*, *Übergang: Auflodern*, *Ton: Triangel*).
- Flare and triangle only on a refresh that raises the streak, `VERDICT_MS` after it lands; none on mount, decrease, reduced motion or background tab. Triangle only for `meId`.
- Code, comments, commits English; user-facing German uses `„…“`. Kotlin: named arguments from two arguments on. Commit rules per `CLAUDE.md`.
- Each frontend commit: `pnpm test`, `pnpm lint` (no `warning` in output), `pnpm exec vue-tsc -b`. Each backend commit: `./mvnw test -Dtest='RoundPlayPointsTest,RosterEndpointTest'`; full `./mvnw clean test` once at the end.

## Review Focus

- No active edition / nobody played → `streak` 0, no icon → Task 1 test.
- Unmount while a flare is pending → no late flare, no triangle → Task 5 test.
- Two refreshes inside `VERDICT_MS` (second guess, ballot) → one flare to the newest value, at most one triangle → Task 5 test.
- Row still flying in when the first refresh lands → no triangle for the values the row mounted with → Task 5 test.
- Icon at 50+ clipped by the settled row (`overflow-x-auto`) → Task 7 manual check in the browser pane.
