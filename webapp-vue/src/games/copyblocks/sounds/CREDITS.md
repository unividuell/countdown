# Sample credits

Minecraft's dig sounds for stone, grass and gravel, and its glass break sound, taken from
minecraft.wiki. They are the only block sounds there from an openly licensed Freesound source
(all other block sounds are © Mojang); Blockierung's block types were chosen to fit them. Each one is
Mojang's edit of a Freesound recording; the license is the recording's, checked on Freesound
itself (2026-10-16), not the wiki's label: the wiki marks gravel CC BY 4.0, while its own source
line and Freesound say CC BY-NC 4.0.

**Changes:** converted from Ogg Vorbis to AAC (`.m4a`, 64 kbit/s), file names shortened.
